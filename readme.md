# The Web Development Trinity

This repository contains resources providing an introduction into each of the three key technologies for developing modern web pages.

[Click here for HTML](HTML_tutorial/HTML_intro.md)  
[Click here for CSS](CSS_tutorial/CSS_intro.md)  
[Click here for JavaScript](JS_tutorial/js_intro.md)

Once you have reviewed the preceding tutorials explore the sample_website provided to see how many of the elements are implemented.

While doing so try to identify:

- Which CSS selector styles the navigation links?
- Which Flexbox properties control the menu cards?
- Which JavaScript event runs when "Show Today's Special" is clicked?
- Where is the array used?
- Which function updates the page content?
- What makes the card hover animation work?
- How does the responsive layout activate on mobile screens?
- Which HTML elements are semantic elements?
- How does the form validate that a name has been entered?

You could update the provided code to match your project scenario, or use it as inspiration for starting from scratch.
